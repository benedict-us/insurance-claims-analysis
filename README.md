# insurance-claims-analysis

# Customer Risk & Claims Analysis for an Insurance Company (Ubuntu Insurance Ltd)

## 1. Project Overview
This project was completed as part of the Data Analytics Foundations Programme offered by DataForge Africa.
This project simulates a real-world business scenarion for Ubuntu Insurance Ktd, where increasing claim costs, suspected fraudulent claims, and customer retention challenges were negetively affecting profitability.

As a Junior Data Analyst, my role was to analyse customer, policy, and claims data to uncover business insights and recommend strategies to reduce reisk, improve profitability, and strengthen fraud prevention.
